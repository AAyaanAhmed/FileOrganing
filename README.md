File Organizer

Overview
Smart File Organizer is a Python automation tool that scans a selected folder, identifies files by their extensions, and organizes them into separate folders. It also detects duplicate files, creates a summary report, and records all activities in a log file.

Features
Organize files by extension
Create folders automatically
Detect duplicate files
Generate file summary
Record activity logs
Handle common errors
